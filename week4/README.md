# 4주차: (네트워크)

## 1. 이번 주 핵심 개념
- (IP 주소와 포트의 역할): IP주노는 네트워크에서 "어느 컴퓨터인지"를, 포트는 그 컴퓨터 안에서 "어느 서비스인지"를 구분한다
- (IP 주소) : 네트워크에서 장치를 식별하기 위한 주소
- (포트) : 컴퓨터에서 제공하는 서비스를 구분하는 번호
- (공인 IP) : 인터넷에서 라우팅 가능한 주소(전체에서 유일)
- (사설 IP) : 해당 사설 네트워크 내부에서 사용하는 주소
- (127.0.0.1 = localhost = 나 자신) : 네트워크를 통해 다른 컴퓨터를 찾아가는 주소가 아닌, '내 컴퓨터 자신을 가리키는 주소'
- (DNS의 역할): 도메인 이름에 대응하는 IP 주소를 찾는 역할 ( DNS = 도메인이름 -> IP주소 )
- 서버는 특정 포트에서 요청을 기다리며, 이미 사용 중인 포트를 다시 사용하며녀 포트 충돌이 발생할 수 있다.


## 2. 실습한 명령어
- `ip addr` : 내 컴퓨터의 모든 네트워크 인터페이스아 IP 주소 정보를 보여준다
- `ip addr show eth0` : 여러 인터페이스 중 `eth0`의 정보만 골라서 보여준다
- `hostname -I` : 내 컴퓨터의 IP주소만 간단하게 출력한다
- `curl` : 터미널에서  URL로 요청을 보내고 응답을 받아 온다.
- `curl ifconfig.me` : 외부 사이트에 요청해서 내 공인 IP를 확인한다
- `ping` : ICMP를 이용하여 장치의 응답 여부 확인 ( + ping 이 실패한다고 서버가 죽어있는것은 아니다. )
- `dig` = domain information groper
- `nslookup` : name server lookup
- `jq` : JSON 데이터를 터미널에서 보기 좋게 출력하거나, 원하는 값만 추출 및 가공하는 명령줄 도구
- `ss`: LISTEN 포트
- `tlnp` : t = TCP, l = listen(대기), n = 숫자, p = 프로세스
- `python3 -m http.server 8080 --bind 0.0.0.0 ` : 모든 네트워크 인터페이스에서 연결을 받겠다 는 

## 3. 어려웠던 점과 해결
- (음에는 `ip addr`의 출력이 너무 길어서 어디가 내 IP인지 찾기 어려웠다. `hostname -I`와 `ip addr show eth0`으로 범위를 좁혀서 확인하니 쉽게 찾을 수 있었다.)

## 4. 느낀 점
- (- 사설 IP와 공인 IP가 다르다는 걸 `curl ifconfig.me`로 직접 확인해 보니 이해가 잘 됐다. 앞으로 서버를 띄울 때는 어떤 포트를 쓰고 있는지 `ss -tlnp`로 먼저 확인하고 싶다.)
